Web Scraping Data Validation Pipeline

A TypeScript backend workflow for scraping product data, validating records, and preparing JIRA-style reports for data quality issues.

Pipeline Readiness

  • Product scraping from a demo e-commerce catalog
  • Validation for missing titles and low prices
  • JIRA-style reporting for invalid records
  • Per-source rate limit and cooldown tracking
  • Block detection for HTTP status and page-content signals
  • Direct, custom, and anyIP-style proxy configuration

Local Commands

Run with npm start and type-check with npm run typecheck.
